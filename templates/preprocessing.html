Flight Data Preprocessing

Missing Values

Handle missing values in departure time, arrival time, elapsed time, delay causes and cancellation-related fields.

Data Cleaning

Remove duplicate records, resolve inconsistent flight information and validate numerical flight attributes.

Categorical Encoding

Encode categorical features such as airline, origin airport, destination airport, tail number and cancellation reason.

Feature Scaling

Normalize numerical features such as departure delay, taxi time, air time, distance and scheduled duration.

Time Features

Process year, month, day, day of week and scheduled departure and arrival times to capture temporal patterns.

Delay Classification

Prepare the Delay column as the target variable for predicting whether a flight is delayed.

Flight Data Preprocessing Workflow

Raw Flight Dataset → Data Cleaning → Missing Value Handling → Feature Extraction → Categorical Encoding → Feature Scaling → Delay Classification → Processed Dataset

Dataset Features

Dataset Size: 120,000 flight records

Features: Flight date, airline, flight number, origin and destination airports, scheduled and actual departure/arrival times, departure delay, taxi times, air time, distance, cancellation information and delay causes.

Target Variable: Delay
